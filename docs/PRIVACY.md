# 参赛者隐私与数据处理说明

## 处理目的

本工具用于 Agent 比赛期间的实时成绩展示、连续性监督和人工复核辅助。

## 采集内容

- 赛事身份：管理员分配的参赛者编号、插件安装实例 ID。
- 账号标识：TsecBench 用户名、组织、Agent 名称；首次观测的用户名作为参赛 Token 的绑定账号。
- 跑分数据：run ID、状态、当前/最终成绩、题目与 Flag 完成数、得分时间线（按服务端接收时间绘制）。
- 监督信号：请求来源 IP、页面心跳和粗粒度设备信息（平台、Chrome 主版本、屏幕分组、时区、语言、CPU 并发数和设备内存分组）。

## 不采集内容

工具不读取或上传 Cookie、密码、登录/Benchmark Token、VPN 配置、Flag 原文、容器地址、模型 API Key、日志、终端输入、LLM 对话、Local Storage、Session Storage 或浏览历史。

## 展示范围

- 公开成绩页：选手显示名、TsecBench 用户名、Agent、成绩、状态和核验标记。
- 管理员控制台：根据主办方配置显示来源 IP、粗粒度设备信息和自动风险标记。

## 存储、保留与撤回

数据存储在赛事管理员指定的服务器。应用默认只保存加盐的 IP 摘要；主办方可显式启用原始 IP 存储。反向代理、托管商及备份的保留期由主办方管理。默认自动清理 30 天前的跑分、事件、IP 和设备记录；参赛者注册记录保留到管理员删除。参赛者可在扩展设置中随时关闭采集、撤回同意或清除本机令牌；已上传数据的删除需联系赛事管理员。
