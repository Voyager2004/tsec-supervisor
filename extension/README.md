# TsecBench 赛事监督扩展

## 系统要求

- macOS 12+ 或 Windows 10/11。
- Google Chrome 111 或更高版本。
- 可访问 TsecBench 和赛事 HTTPS 汇总服务器。

扩展是纯 Manifest V3 JavaScript/CSS/HTML，不包含 macOS 或 Windows 专用代码，不需要安装系统服务、驱动或 native host。

## macOS 安装

1. 双击发布 ZIP 完成解压。
2. 在 Chrome 输入 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
5. 打开扩展详情页的“扩展程序选项”完成配置。

## Windows 安装

1. 右键发布 ZIP，选择“全部解压缩”。不要直接从 ZIP 预览窗口加载。
2. 在 Chrome 输入 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
5. 打开扩展详情页的“扩展程序选项”完成配置。

## 连接到比赛

打开扩展设置，核对汇总服务器与主办方公布的地址一致。输入主办方单独签发的参赛者令牌，勾选同意和启用，然后点击「保存并测试连接」。若显示其他比赛地址，请向主办方领取本场的扩展包。

## 比赛前自检

1. 设置页显示正确的选手名和编号。
2. “保存并测试连接”显示连接成功。
3. 扩展图标显示绿色状态点，待上传数量为 0。
4. 进入 TsecBench 本地模式后，管理员面板能看到心跳和成绩更新。

Chrome 更新或重启后不需要重新配置。如果管理员轮换了选手 Token，需在设置页填入新 Token。
